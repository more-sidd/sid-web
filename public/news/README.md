# News cover images

Put cover images for News items here and reference them from a post as
`/news/your-file.jpg`:

```markdown
---
cover: /news/revolute.jpg
coverAlt: Teams working on robot arms
---
```

Name files lowercase with hyphens — `revolute-hackathon.jpg`, not
`Revolute Hackathon.JPG`. Capitals and spaces broke every image on this site
once already, because the server is case-sensitive even though Windows isn't.

See [BLOG.md](../../BLOG.md) for the full writing guide.
